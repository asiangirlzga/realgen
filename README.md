# RealGen

Android app with an embedded Python server (Chaquopy) that generates realistic
images, 10 per batch. The UI is a mobile web page shown in a WebView.

## How it works
- `app/src/main/python/server.py` runs on `127.0.0.1:8765` inside the app.
- Images are generated by the free community network **Stable Horde**
  (realistic Stable Diffusion models, no GPU needed on the phone).
- Prompts are wrapped with photo-style keywords and a negative prompt to get a
  realistic look similar to Perchance's ultra-realistic generator.
- "Save" writes images to `Pictures/RealGen`.

## Build the APK on GitHub
1. Create a new GitHub repo and push this folder to the `main` branch.
2. Open the **Actions** tab and run **Build APK** (it also runs on every push).
3. Download the `RealGen-debug-apk` artifact, unzip it, and install the APK
   (allow "install unknown apps").

## Notes
- Anonymous Horde access can queue for a few minutes at busy times. A free key
  from https://stablehorde.net/register makes it faster; paste it in the app.
- Large sizes may be refused for anonymous users; use 512x512 or 512x768.
- Needs Android 10+ and an internet connection.
- Test the server on a PC: `python app/src/main/python/server.py`, then open
  http://127.0.0.1:8765/
